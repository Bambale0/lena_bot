# [UX2-E06] Навигация, лента и поиск идей без тупиков и потери контекста

Source: https://github.com/Bambale0/lena_bot/issues/215

## Цель, родитель, зависимости
Программа #209. Пользователь всегда понимает, где он находится, как вернуться и где продолжить создание. Лента остаётся стартовым экраном, приложение не превращается в лендинг. Приоритет P1. Пять разделов уже существуют в #208; внедрение можно начинать без ожидания E01–E05. Глубокие переходы в новый редактор согласовать с E02 (#211), в повторы — E03 (#212).

## Вертикальные срезы
- [ ] **E06.1 — единая модель навигации.** Разделы Лента/Тренды/Создать/Работы/Профиль и вложенные экраны имеют явного родителя. Browser Back и Telegram Back сначала закрывают верхний overlay, затем возвращают по истории, не выбрасывают всегда в ленту. Несколько наложенных модалок не закрываются одним нажатием сразу. Подсветка раздела соответствует текущему экрану.
- [ ] **E06.2 — восстановление контекста ленты.** Просмотр→повтор→отмена и переход в Работы сохраняют сортировку, filters, loaded page и scroll anchor. Прокрутка восстанавливается по стабильному ID, не случайному пикселю после изменения сетки. Обновление данных не дублирует карточки и не сбрасывает читаемую позицию.
- [ ] **E06.3 — разделение ленты и каталога.** Лента показывает работы сообщества; каталог трендов — подготовленные сценарии. Второй независимый trends list внутри ленты убирается или становится согласованной ссылкой. «Мои работы» ведут в библиотеку, не в другой неполный список публикаций. Существующие deep links сохраняются через совместимый маршрут.
- [ ] **E06.4 — крупные понятные карточки.** На мобильном достаточно места для медиа, краткого названия и одного главного действия. Технические параметры в деталях, не текст 9px на каждом превью. Фото/видео видны по типу, не только по значку. Изображение открывает просмотр; repeat не срабатывает случайно на всей карточке.
- [ ] **E06.5 — фильтры и поиск.** Все/Фото/Видео и сортировка имеют независимые и понятные значения. Поиск/категории трендов показывают результат, loading, error и пустую выдачу со сбросом. Не утверждать, что результатов нет, пока выполнена только локальная фильтрация первой страницы. Список категорий приходит из подтверждённого каталога/control plane.
- [ ] **E06.6 — входы из бота и ссылок.** feed/remix/trend/prompt/task/profile и сервисные ссылки открывают нужный объект, а не первый элемент. Неавторизованный вход объясняет необходимость Telegram; после входа намерение сохраняется без платного автозапуска. Удалённая/private ссылка не раскрывает объект и не ломает остальной Mini App.

## Приёмка
- [ ] Каждый пункт меню ведёт на реальный работающий экран, без закольцованных «Сервисы→Сервисы».
- [ ] Основное меню помещается на 320 CSS px, один active destination.
- [ ] Back возвращает ожидаемый уровень; overlay не ломает историю.
- [ ] Позиция и фильтры переживают просмотр/редактор/оплату.
- [ ] Лента и Работы не дают противоречащих списков одной сущности.
- [ ] Deep link не запускает generation POST; у private/deleted item безопасное состояние.
- [ ] Ошибка медиа затрагивает одну карточку, не весь экран.

## Тесты
Навигационная таблица всех переходов + Playwright tests каждой дуги. Мобильные размеры 320/360/390/430, desktop Mini App 768; deep-link с корректным/чужим/несуществующим ID; 10 повторных forward/back; 300+ элементов; offline during pagination; mixed media; scroll restore после вставки новых карточек; отсутствие случайных paid POST. Проверить старые user-journey tests и публичные ссылки в текстовом боте без смены бизнес-логики.

## Нефункциональные требования
Не монтировать сотни видео, preload ограничен, autoplay уважает действия пользователя и reduced motion. Использовать стабильные keys и ограниченный DOM; не возвращать CSS balanced columns, из-за которых прыгает сетка. Навигационные события содержат screen/from/to/source kind и длительность, но не auth-параметры и private IDs в публичной аналитике.

## Выпуск
Небольшие UI-only PR под admin preview. Rollback не меняет task ownership/URLs. Дизайн-система E08 применяется к компонентам, но миграция маршрутов не зависит от полного визуального редизайна. Эпик закрывается по проверенному графу переходов и сохранённому контексту, а не по числу новых вкладок.
