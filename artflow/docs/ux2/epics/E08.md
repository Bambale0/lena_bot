# [UX2-E08] Дизайн-система, доступность и реальный Telegram WebView

Source: https://github.com/Bambale0/lena_bot/issues/217

## Цель и зависимости
Программа #209. Интерфейс читаем, управляем пальцем и клавиатурой, не ломается при маленьком экране, клавиатуре, светлой теме и сворачивании Telegram. Приоритет P1. Начальная работа доступна после #208; каждый новый экран из E01–E07 проверяется сразу, не в самом конце. Финальная приёмка требует всех пользовательских путей выбранного релизного объёма.

## Вертикальные срезы
- [ ] **E08.1 — система компонентов.** Единые tokens для пространства, типографики, foreground/background/accent/error, границ и радиусов; состояния buttons/fields/cards/sheets/loading/error/empty. Сохранить фирменную тёмную фиолетовую основу, светлую тему проектировать отдельно. Не вводить новый шрифт без лицензии и проверки кириллицы. Не маскировать price или destructive action визуальной иерархией.
- [ ] **E08.2 — малые экраны и касания.** Ширины 320/360/390/430/768, высота 568, landscape, увеличенный текст 200%. Внутренний target 44×44 CSS px для действий, основное поле 16px, подписи не сжимаются ради плотности. Панель запуска и нижняя навигация не перекрывают друг друга; шапка с балансом не исчезает автоматически из-за высоты.
- [ ] **E08.3 — клавиатура и safe-area.** Централизованный Telegram viewport/content-safe-area/insets adapter с fallback при старом SDK. При открытии клавиатуры видны активное поле, ошибка и действие; bottom offsets не суммируются дважды. Проверить portrait/landscape и закрытие клавиатуры без скачка списка.
- [ ] **E08.4 — доступность и модалки.** Accessible names, label/description/error association, focus order, focus trap только верхнего overlay, Escape/Back и возврат к opener. Не использовать цвет как единственное обозначение статуса. Loading status озвучивается умеренно через aria-live; reduced motion прекращает декоративную анимацию. Проверить контраст 4.5:1 обычного/3:1 крупного текста, включая disabled/help.
- [ ] **E08.5 — реальные устройства.** Чек-лист Telegram iOS и Android с версией ОС/Telegram, шириной, записью результата, actor scope. Проверить file picker/camera/video, сворачивание, возврат из браузера оплаты, скачивание, отсутствие доступного bot chat. Playwright WebKit не приравнивать к Telegram iOS; desktop Chromium не приравнивать к телефону.
- [ ] **E08.6 — визуальная регрессия и производительность.** Снимки основных экранов во всех состояниях плюс screenshot diff после смены tokens. Исключить реальный private контент из artifacts. Проверить количество media requests, long tasks и layout shifts на слабом профиле; не вводить бесконечные тяжёлые blur/glow/автоплеи. Фиксировать реальные замеры с устройством, не объявлять абстрактный балл 100.

## Приёмка
- [ ] Все критические действия доступны без горизонтального scroll документа.
- [ ] На 320×568 баланс, ошибку и запуск можно найти/нажать.
- [ ] Клавиатура не закрывает focused input и основное действие.
- [ ] Все интерактивные элементы имеют names и keyboard/focus поведение.
- [ ] Светлая и тёмная темы проходят контраст, видимость disabled/error/focus.
- [ ] Modal/back/toast не блокируют оплату и не закрывают несколько уровней случайно.
- [ ] Проверенные реальные iOS/Android сценарии имеют воспроизводимое evidence.

## QA-матрица
Chromium + WebKit; 5 ширин; light/dark; RU/EN; empty/loading/ready/error; 200% текста и reduced motion. Не обязательно полное декартово произведение: полный критический маршрут на mobile core, pairwise для вторичных сочетаний. Все найденные P0/P1 получают regression test. Снимки проверяются глазами; green assertions не заменяют визуальный осмотр. Полный live checkout только с разрешённым бюджетом.

## Выпуск и доказательства
Tokens внедрять через scoped UX2 слой, не ломать старый интерфейс и legacy rollback. Gate: список проверенных экранов, размеры, screenshot hashes, accessibility defects, performance measurements и нерешённые ограничения. Никаких заявлений «доступно всем», пока не проведены соответствующие проверки. Широкий пилот блокируется недоступной критической кнопкой/полем на реальном WebView.
