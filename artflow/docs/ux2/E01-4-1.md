# E01.4.1 - Local reference availability

Issue #229; parent #226. Base 5523593bdf15eda6b05ff2af3f318c2c52a551a7.

## User outcome
For ordinary admin-preview photos, a URL is not treated as proof that a file still exists. On editor/reload/replacement, each completed material gets a transient state and explicit retry on failure. Before paid generation, every included photo is checked again. Missing/unknown/forbidden/network failure aborts before generation POST and leaves description, canonical list and inclusion untouched. Parked photos do not block the request.

## Contract
POST /api/web/upload-media/check with {url:string} returns {ok:true,data:{status}}. Authentication401; existing server admin membership403. State only, no URL/path/content returned. Only canonical generated photo filenames within configured miniapp public upload directory are inspected. No DNS, redirects, external network or link renewal. Syntax/traversal/private literals/symlink escapes rejected; filesystem denial is temporary_error, not missing. Unknown external URLs require device upload or explicit exclusion.

## Integration and acceptance
ReferenceAvailabilityNotice uses an abortable current-source effect. App preflight always requests fresh states under a total timeout, rechecks owner and full draft snapshot before launch. On failure cached display is invalidated. Checking again never launches. Neither state nor approval is persisted: reload means new inspection. Model/provider/ledger APIs unchanged. No broad rollout.

## Tests
Backend: public local regular/empty/missing, malformed path, private host, query, symlink, I/O denial, no-network assertions, auth/admin, no secret logging. Browser: positive exact active payload, missing and unknown negative POST, parked invalid media, reload, delayed replace/delete/owner change, retry and 320px light/dark. Existing 300 journeys and maintained smoke remain mandatory.

## Deliberate remaining work

Public-file existence does not guarantee reachability from a provider or protect against cleanup after the check. Real Telegram and paid provider operations not verified.
