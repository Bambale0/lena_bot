# Фото → Промпт

Функция анализирует отправленное пользователем изображение и генерирует детальный текстовый промпт, позволяющий максимально точно воспроизвести это изображение через любую AI-генерацию.

## Пользовательский флоу

1. Пользователь нажимает **📸 Фото → Промпт** (кнопка доступна на экранах: выбор сценария, активная серия, после результата генерации).
2. Бот просит отправить фотографию.
3. Пользователь присылает фото — бот показывает `⏳ Анализирую фотографию…`.
4. Промпт готов — бот показывает текст в `<code>…</code>` для лёгкого копирования.
5. Если есть активная серия — появляется кнопка **✅ Сгенерировать сейчас**, которая сразу запускает генерацию в этой серии.
6. Кнопка **❌ Отмена** возвращает на предыдущий экран.

## Технические детали

### API: KIE.AI GPT-5.x Vision

| Роль     | Переменная окружения         | Дефолт      | Эндпоинт KIE                                    |
|----------|------------------------------|-------------|--------------------------------------------------|
| Primary  | `KIE_PHOTO_PROMPT_MODEL`     | `gpt-5-2`   | `POST /gpt-5-2/v1/chat/completions`             |
| Fallback | `KIE_PHOTO_PROMPT_FALLBACK`  | `gpt-5-5`   | `POST /gpt-5-5/v1/chat/completions`             |

- **Base URL:** `https://api.kie.ai`
- **Auth:** `Authorization: Bearer {KIE_AI_KEY}` (тот же ключ, что и для генерации изображений)
- **reasoning_effort:** `"high"` (фиксировано — лучшее качество анализа)
- Изображение передаётся как base64 data URL: `data:{mime};base64,...`
- Таймаут: 90 секунд

При ошибке primary-модели автоматически делается повторный запрос к fallback. Если оба вызова упали — пользователь видит сообщение об ошибке, кредиты не тратятся.

### Переменные окружения

```env
# KIE_AI_KEY уже должен быть задан для генерации изображений
KIE_AI_KEY=your_kie_key

# Опционально — переопределить модели
KIE_PHOTO_PROMPT_MODEL=gpt-5-2
KIE_PHOTO_PROMPT_FALLBACK=gpt-5-5
```

### Файлы

| Файл | Назначение |
|------|-----------|
| `api/photo_prompt_service.py` | Вызов KIE GPT-5.x vision, логика primary/fallback |
| `bot/handlers/image_gen.py` | Хэндлеры `cb_photo_to_prompt`, `handle_photo_to_prompt`, `cb_use_generated_prompt`, `cb_cancel_prompt` |
| `bot/keyboards/models.py` | Кнопка в `image_session_kb`, `image_active_kb`, `image_scenarios_kb` |
| `bot/states/__init__.py` | Состояние `ImageGenFSM.photo_to_prompt` |
| `core/config.py` | Поля `KIE_PHOTO_PROMPT_MODEL`, `KIE_PHOTO_PROMPT_FALLBACK` |

### Callback-данные

| Callback            | Описание |
|---------------------|---------|
| `img:photo2prompt`  | Открыть режим фото→промпт |
| `img:use_prompt`    | Использовать сохранённый промпт для генерации |
| `img:cancel_prompt` | Отмена, возврат на предыдущий экран |

### Системный промпт

Модель получает инструкцию описать изображение с учётом: субъекта и главных элементов, стиля и техники, композиции, освещения, цветовой палитры, настроения, текстур, угла камеры. Ответ — только готовый промпт на английском, без пояснений.
