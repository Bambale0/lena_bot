# Тренды APIX

## Telegram-бот

- Главная кнопка `👑 Тренды` открывает `menu:top_day`.
- Команда `/trends` открывает тот же источник.
- В карточке можно переключаться между `🔥 Все работы` и `👑 Тренды`.
- Источник использует `repo.get_top_day_generations` и ранжирование по вовлечённости.

## Mini App

- На главной добавлена карточка `Тренды работ`.
- Внутри ленты есть переключатель `🔥 Все работы / 👑 Тренды`.
- Тренды загружаются отдельно через `/api/v1/feed?source=top_day`.
- При переходе на тренды меняются заголовок, состояние загрузки и empty state.
