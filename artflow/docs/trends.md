# Админские тренды APIX

Тренды не являются рейтингом пользовательской ленты. Это курируемая администратором витрина готовых шаблонов поверх `user_prompts`.

## Признаки

- обязательный системный тег `trend`;
- для видео — дополнительный тег `trend-video`;
- параметры шаблона хранятся в тегах `trend-scenario:*`, `trend-duration:*`, `trend-ratio:*`, `trend-quality:*`, `trend-resolution:*`;
- запись опубликована только при `status=approved` и `is_public=true`.

## Безопасность

Публичный `GET /api/v1/trends` не возвращает `prompt_text`. При повторе клиент передаёт `prompt_id`, а `/generate/image` и `/generate/video` повторно загружают канонический prompt из БД. Для тренда также проверяется закреплённая модель. Публичные ответы генерации скрывают prompt через `input_params.hidden_prompt`.

Создание, изменение, загрузка preview и архивирование доступны только пользователям из `ADMIN_IDS`; право проверяется на backend.

## Mini App

Раздел `Тренды` содержит отдельные фото- и видео-секции. Администратор видит форму:

- тип;
- название и описание;
- активная модель из backend bootstrap;
- preview;
- скрытый prompt;
- настройки фото или видео.

Архивирование выполняется мягко: `status=deactivated`, `is_public=false`.

## Telegram

Команда `/trends` и кнопка `👑 Тренды` показывают шаблоны по одному. Администратор дополнительно видит мастера загрузки фото/видео и кнопку архивации. Фото-тренд запускается в текстовом боте; видео-тренд открывается в Mini App с уже выбранными моделью и настройками.


## Категории и стартовый экран Mini App

Главный экран Mini App является витриной админских трендов. Администратор выбирает категорию при публикации; категория хранится в системном теге `trend-category:<slug>`. Старые записи без тега относятся к `featured`. Публичный API возвращает `category`, `category_title` и `category_emoji`, но по-прежнему не возвращает канонический prompt.
