# Админские тренды APIX

Тренды не являются рейтингом пользовательской ленты. Это курируемая администратором витрина готовых шаблонов поверх `user_prompts`.

## Признаки

- обязательный системный тег `trend`;
- для видео — дополнительный тег `trend-video`;
- параметры шаблона хранятся в тегах `trend-scenario:*`, `trend-duration:*`, `trend-ratio:*`, `trend-quality:*`, `trend-resolution:*`;
- запись опубликована только при `status=approved` и `is_public=true`.

## Безопасность

Публичный `GET /api/v1/trends` не возвращает `prompt_text` и внутренние настройки модели. В Mini App и на сайте повтор проходит через `GET /api/v1/trends/{id}/checkout`, загрузку исходного фото и `POST /api/v1/trends/{id}/run`. Сервер берёт канонический prompt и модель из БД, проверяет подписанный asset пользователя, цену и баланс. Для Wan цена из checkout должна быть подтверждена полем `quoted_credits`; если тариф изменился, API возвращает `409` с кодом `trend_quote_stale`, а клиент загружает новую цену для повторного подтверждения.

Запуск защищён уникальным ключом `(user_id, idempotency_key)` в `trend_run_claims`. Повтор с тем же телом возвращает ранее созданную задачу; неопределённый исход не запускает второго платного запроса. Доказанный отказ до отправки провайдеру освобождает ключ для повторной попытки. Публичные ответы генерации скрывают prompt через `input_params.hidden_prompt`.

Создание, изменение, загрузка preview и архивирование доступны только пользователям из `ADMIN_IDS`; право проверяется на backend.

## Mini App

Раздел `Тренды` содержит отдельные фото- и видео-секции. Администратор видит форму:

- тип;
- название и описание;
- активная модель из backend bootstrap;
- preview;
- скрытый prompt;
- настройки фото или видео.

Архивирование выполняется мягко: `status=deactivated`, `is_public=false`.

## Telegram

Команда `/trends` и кнопка `👑 Тренды` показывают шаблоны по одному. Администратор дополнительно видит мастера загрузки фото/видео и кнопку архивации. Все фото- и видео-тренды, в том числе без настраиваемых полей, открывают общий runner в Mini App. В бот-callback нет прямого запуска генерации и списания: фотография пользователя, подписанный asset, checkout и `trend_run_claims` обрабатываются общим серверным маршрутом. Скрытый prompt в сообщение не передаётся. Статус остальных замечаний — в [отчёте исправлений](audits/2026-10-16-remediation.md).

Для новых трендов Gemini Omni допустимы длительности 4, 6, 8 и 10 секунд; админские API и интерфейсы отклоняют 5 секунд. Ранее опубликованные записи с `trend-duration:5` при checkout и запуске интерпретируются как 4 секунды для совместимости.


## Категории и стартовый экран Mini App

Главный экран Mini App является витриной админских трендов. Администратор выбирает категорию при публикации; категория хранится в системном теге `trend-category:<slug>`. Старые записи без тега относятся к `featured`. Публичный API возвращает `category`, `category_title` и `category_emoji`, но по-прежнему не возвращает канонический prompt.
