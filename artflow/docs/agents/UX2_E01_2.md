## Scope and decisions
Ordinary React drafts in admin UX2 only. Add include/exclude/delete for photo references, including those used by video/motion; video/ID exclusion and enhancer side state stay outside this slice. Existing quote/price/ownership/provider APIs are authoritative. No new billing rules or live paid tests.

One canonical optional `referenceMaterials` list owns stable local id, URL and inclusion. Existing `referenceUrls` are used only for legacy drafts or a generated request projection, never as an independently editable duplicate. Selecting a material upgrades that ordinary draft; existing v1 drafts map to all-active items. All validation/price/POST consumers use one pure active projection. Legacy UI receives only active input; parked files stay retained. Model switching never auto-includes parked inputs.

A v2 owner-scoped storage key stores the canonical snapshot; a generated v1 mirror contains ONLY active refs for old-code rollback. The full v2 snapshot is never reconstructed from that projection. Unknown/corrupt v2 data is not replaced automatically and does not fall back to potentially stale all-active v1. Full rollback edits are not silently merged into the preserved v2 snapshot. No cross-device/asset-TTL guarantees.

Before selected-material submission: lock the operation, fetch current model metadata using existing model endpoints, compare pricing/capabilities, stop for a new user confirmation when changed, validate the same immutable active snapshot, then POST. No automatic retry on uncertain generation response.

## Review limitations kept explicit
The preflight compares current metadata before a selected-material request, but does not introduce an atomic server-side quote/price lock. A price change between GET and POST remains the existing API's responsibility and is tracked by E07. The synchronous lock prevents duplicate simultaneous clicks, not uncertain-response reconciliation across reloads (E04). Physical WebView/version-specific support, including local-id browser APIs, remains subject to E08 device checks.
