## Preflight and scope
Ordinary admin UX2 photo references only. Existing legacy/template/enhancer paths remain.
Upload API returns url/kind/content_type/size and no asset ID. Existing server image limit is MAX_WEB_REFERENCE_IMAGE_BYTES; publish it through an authenticated read-only policy rather than duplicate a frontend limit.
Current batch handler only appends after all uploads succeed, so later failure loses acknowledged earlier results.

## Design
Canonical ReferenceMaterial holds serializable per-file operation/stage and metadata. Actual File, preview object URL and AbortController live in memory only. Completion is guarded by owner, draft kind, material ID and operation ID. Replacement keeps original until success. Sequential transfer and manual retry remain.
Storage v3 retains pending/error entries. Older mirrors contain only ready inputs; restore requires reselecting an interrupted source. No cross-device/permanent-media promise.
